# SportGoods Client

React, TypeScript, and Vite frontend for the SportGoods application.

## Local configuration

The client reads `VITE_API_URL` from:

- `.env`
- `.env.development`
- `.env.local`

All local defaults point to `http://localhost:5192/api`, matching the backend development launch profile.

## Scripts

- `npm run dev`
- `npm run typecheck`
- `npm run lint`
- `npm run build`
- `npm run test`
